File: harness/agent.py:55

ThinkingStart/Delta/Stop, ToolUseStart/InputDelta/Stop, ToolResult,

Fix applied in _oauth_request_hook() (harness/agent.py:73):

    1. Force-override user-agent to "claude-cli/2.1.2 (external, cli)"
    2. Force-override x-stainless-lang/runtime/os/arch/package-version
       to CLI-shaped values
    3. Strip empty x-api-key left by the SDK's auth_token mode
    4. Append ?beta=true to /v1/messages URLs
    5. Merge interleaved-thinking-2025-05-14 into anthropic-beta
       alongside oauth-2025-04-20

Reference source inspected for canonical pattern:
    /home/node/.claude/file-history/3e82c098-c80f-4d52-bc1c-d262b7b27bbf/41b6e60962445c8e@v4
    (anthropicOAuthFetch.ts, Claude Code's own OAuth fetch wrapper).

Post-fix verification: outgoing request headers confirmed clean via httpx
event_hook inspection on claude-haiku-4-5-20251001. Headers land as:

    user-agent:        claude-cli/2.1.2 (external, cli)
    anthropic-beta:    oauth-2025-04-20,interleaved-thinking-2025-05-14

token bucket with the concurrent live Claude Code session was exhausted. The

succeed when the bucket refills.

2.2 Catalog and seed generation
--------------------------------------------------------------------------------

frontier_catalog_generator.py:163
    generate_catalog(output_dir, categories, target, batch_size,
                     max_batches_per_category, concurrency, model, ...)
    returns List[ExtractedSkill]

For each category in categories dict, generates batches of N skills with
running dedup of already-emitted names. Emits skills.json (drop-in seed for
frontier_kway_extractor.py), catalog.json ({category: [name...]}), and
generation-transcripts.jsonl.

Parallelization: ThreadPoolExecutor with shared anthropic.Anthropic client
across threads (the SDK is thread-safe). transcripts_out file handle
protected by a threading.Lock instance held in the closure.
_process_category() (frontier_catalog_generator.py:126) is the per-worker
entry point.

frontier_novel_skill_elicitor.py:243
    elicit_novel_catalog(output_dir, root_count, subskills_per_root, ...)
    returns List[ExtractedSkill]

Two-stage elicitation:
    Stage A: elicit_roots() asks the model for "broad skills that have NO
             widely-used conventional name but are recognizable once named".
    Stage B: expand_subskills() runs per-root, producing M subskills each.

Output format: root ExtractedSkill records use category="novel-root";
subskill ExtractedSkill records use category=<root.name> so the parent-child
relationship is preserved in the flat skills.json.

2.4 Agentic verification and revision
--------------------------------------------------------------------------------

frontier_verifier.py:172
    verify_tasks(tasks_path, output_dir, limit, ...)
    returns List[ExtractedTask]

For each ExtractedTask, the frontier model returns:

    per_skill:   List[{skill_name, exercises (bool), rationale}]
    overall:     {exercises_all (bool), summary}

A task passes iff every per_skill.exercises flag is true AND
overall.exercises_all is true. Output files:
    verified-tasks.json              (ExtractedTask list)
    rejected-tasks.jsonl             (with per-skill verdicts)
    verification-transcripts.jsonl   (full Transcript per task)

frontier_reviser.py:208
    revise_tasks(tasks_path, rejections_path, output_dir, ...)
    returns List[ExtractedTask]

Joins original ExtractedTask records (by task_uid) with rejected-tasks.jsonl
entries from the verifier, then asks the model to produce a revised task
that directly addresses each "exercises: false" rationale. Output
ExtractedTask records carry acceptance_criteria.revised_from_task_uid for
provenance, and extraction_method suffixed with "-revised-v1".

ADDENDUM: OAUTH RATE-LIMIT FIX RESOLVED (same day)
================================================================================

The fix described in Part 1.3 was INCOMPLETE. Hand-rolled header overrides
and URL rewrite did not resolve Opus/Sonnet 429 errors. The missing piece
was located in a peer package at /workspace/anthropic-oauth.

--------------------------------------------------------------------------------
A.1 Root cause (precise)
--------------------------------------------------------------------------------

The Anthropic OAuth endpoint requires the "system" field of the request
body to be a LIST OF TEXT CONTENT BLOCKS with the Claude Code identity
as the FIRST block, NOT a single concatenated string.

Reference: /workspace/anthropic-oauth/anthropic_oauth/transform.py:162-182
           RequestTransformer.transform_body()

Transformation applied by the package for a string system:
    system_string  ->  [
                         {"type": "text", "text": CLAUDE_CODE_IDENTITY},
                         {"type": "text", "text": system_string},
                       ]

Our original harness/agent.py computed:
    system_string  =   CLAUDE_CODE_IDENTITY + "\n\n" + user_system

and passed it through as-is. Haiku tolerated this; Opus and Sonnet did
not and returned HTTP 429 rate_limit_error on every request.

--------------------------------------------------------------------------------
A.2 Fix applied
--------------------------------------------------------------------------------

File: harness/agent.py:55-115

Replaced the hand-rolled OAuth path with the anthropic-oauth package:

    OAuthTransport (httpx.BaseTransport subclass)
        applies header, URL, and body transformations via
        RequestTransformer and delegates to a real httpx transport.

    RequestTransformer
        performs: Bearer auth, beta flag merging, CLI user-agent,
        x-stainless-* fingerprint override, ?beta=true, system-array
        transformation, mcp_ tool name prefixing on requests,
        mcp_ strip on response bodies.

    ClaudeCodeOAuthManager (new subclass of OAuthManager)
        Overrides load_tokens() and save_tokens() to read/write
        ~/.claude/.credentials.json in Claude Code's
        {claudeAiOauth: {accessToken, refreshToken, expiresAt_ms}}
        format, so the harness shares the same active session tokens
        as the Claude Code desktop session.
